A `--offline-rules` CLI run has no answer generation even though it still calls Gnani for speech.
4. Rehearse the chosen query and inspect its JSON: `composition=grounded_llm` means accepted generated wording; `document_excerpts` is explicitly offline source display, `deterministic_guardrail` is an operational guard, and abstention modes mean the agent withheld an unsupported answer. These flags do not prove correctness. Confirm `llm.cache_hit` and timing fields; keep the sanitized JSON trace ready for fields absent from the app caption. 5. Prepare a synthetic order/proof privately. Mask only the input area or enter proof off-screen; the displayed history must show its redaction. Keep app session state clear before the recorded verification example.
6. Choose a documented query, an order follow-up and a handover or uncovered service question. Use a saved baseline only if its actual generated answer demonstrates the claimed difference.
